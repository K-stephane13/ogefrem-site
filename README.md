# OGEFREM - Site Officiel

Site institutionnel de l'Office de Gestion du Fret Multimodal de la RDC.

## 🚀 Fonctionnalités

- Présentation institutionnelle (histoire, missions, organigramme)
- Actualités et communiqués avec système de likes
- Règlementations et documents officiels (77 PDFs)
- Annuaire des mandataires et transitaires
- Services opérationnels (suivi FERI/FERE, mercuriales...)
- Formulaire de contact avec stockage
- Panel d'administration complet

## 🛠️ Technologies

- HTML5 / CSS3 / JavaScript Vanilla
- Bootstrap 5
- FontAwesome 6
- Chart.js
- LocalStorage pour la persistance des données
